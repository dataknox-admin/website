The Hardware

What Is the NVIDIA GB200 NVL72?

The NVIDIA GB200 NVL72 is a rack-scale AI compute system built on the Blackwell architecture — NVIDIA's most advanced GPU platform as of 2025. Each NVL72 rack integrates 72 GB200 GPUs connected by fifth-generation NVLink, delivering a unified memory pool that allows models and workloads to address GPU memory across the entire rack as a single logical unit. This design eliminates the communication bottlenecks that constrain traditional multi-node GPU clusters when training models with hundreds of billions of parameters.

Blackwell Architecture

Blackwell introduces a second-generation transformer engine, fourth-generation NVLink (with NVLink Switch enabling rack-level topology), and a new decompression engine that accelerates data pipelines for large-scale training. The GB200 die itself is manufactured on a 4nm process and pairs the GPU with a Grace CPU in a tightly coupled NVL2 module — two such modules form one GB200 NVL2 compute node, and 36 nodes fill the NVL72 rack.

For operators running frontier language models, diffusion models, or scientific simulation workloads, Blackwell's architecture closes the gap between GPU memory bandwidth and model weight size — a persistent constraint when scaling H100 clusters.

NVL72 Configuration at a Glance

  • 72 GB200 GPUs in a single rack-scale system
  • NVLink fifth-generation interconnect — rack-wide unified memory
  • 288 Grace CPU cores co-packaged with GPU compute
  • Designed for models exceeding 1 trillion parameters
  • High-bandwidth memory (HBM3e) across all 72 GPU dies
  • InfiniBand NDR400 for inter-rack fabric in multi-rack deployments
  • Liquid-cooled direct-to-chip for sustained rack-level TDP

Reinforcement Learning
